Vulnerable Read-Modify-Write

Both transactions read stock=1 into memory, verify stock >= 1, and concurrently write stock=0. Both commit with HTTP 200, but 2 users bought 1 item!

1. T1: READ inventory (qty = 1)
2. T2: READ inventory (qty = 1)
3. T1: UPDATE inventory = 0 -> COMMIT
4. T2: UPDATE inventory = 0 -> COMMIT
Flaw: T1 update overwritten by T2!
AFTER CORRECTION Atomic Guard / SERIALIZABLE
